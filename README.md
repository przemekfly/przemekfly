### 🛠️ W czym mogę Ci pomóc?

- 🚀 **REST API & Mikroserwisy** – Projektowanie i wdrażanie szybkich, skalowalnych interfejsów API w **Node.js (Express / NestJS)** oraz **Pythonie (FastAPI / Django)** z pełną dokumentacją Swagger/OpenAPI.
- 💳 **Integracje Płatności i API** – Wdrażanie bramek płatności (Stripe, PayU, Przelewy24), systemów mailingowych, integracji kurierskich i webhooków.
- 🗄️ **Bazy Danych i Cache** – Projektowanie schematów relacyjnych i nierelacyjnych, migracje, optymalizacja zapytań (PostgreSQL, MySQL, MongoDB) oraz buforowanie z Redis.
- 🔐 **Autoryzacja i Bezpieczeństwo** – Bezpieczne uwierzytelnianie (JWT, OAuth2, sesje), walidacja danych (Zod / Pydantic), ochrona przed atakami (Rate Limiting, CORS, CSRF).
- ⚙️ **Automatyzacja i Background Workers** – Zadania asynchroniczne, kolejki (BullMQ, Celery), web scraping i automatyczne przetwarzanie danych.
